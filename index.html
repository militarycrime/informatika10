Магистрально-модульный принцип построения компьютера

Функциональное устройство: процессор · память · устройства ввода/вывода · шина

Подходы к изучению

  • Семейство ПК
  • Конструкция (настольные, мобильные)
  • Функциональное устройство

Конструкция

  • ПК: системный блок + внешние устройства
  • Ноутбуки, планшеты, смартфоны — всё в одном корпусе
  • Серверы, суперкомпьютеры — «шкафы»
  • Бытовая электроника ближе к ПК

Вывод

Конструкция меняется, но функциональное устройство постоянно.

Магистрально-модульный принцип

Архитектура, расширяемая за счёт подключения к шине новых устройств.

Процессор Память Ввод/вывод Контроллеры

Шина (магистраль)

Группа линий связи для обмена данными между устройствами. Правила обмена — протокол шины.

Запись в память

  • Данные → шина данных
  • Адрес → шина адреса
  • Сигнал записи → шина управления
  • Память сохраняет данные

Контроллер

Схема управления внешним устройством и предварительной обработки данных. Снижает нагрузку на ЦП.

Контроллер HDD

  • Ищет данные по координатам
  • Читает и передаёт в ОЗУ
  • Подменяет дефектные секторы

Прерывания

  • Контроллер прерываний сортирует запросы по приоритету
  • ЦП возвращается к прерванной программе
  • Основа событийных программ и ОС

ПДП (DMA)

  • ЦП только подготавливает обмен
  • Контроллер сам ведёт адрес и счётчик
  • Ускоряет передачу блоков данных

Три части шины

ДанныхПередаёт данные
АдресаКуда передаётся информация
УправленияЧтение/запись, готовность, обращение к памяти
Ключевая идея: общая шина с поочерёдным доступом устройств позволяет подключать новые модули без перестройки системы; данные могут идти между внешними устройствами и ОЗУ напрямую, минуя процессор.
